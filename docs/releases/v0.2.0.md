# Lumos v0.2.0

发布日期：2026-08-25

Lumos v0.2.0 增加登录时自动启动。设置一次后，Lumos 会在你登录 macOS 时直接回到菜单栏，继续等待和守护被关注的 App。

## 这次带来了什么

- **登录时自动启动：** 在“设置 > 控制 > 启动”中直接开启或关闭，不需要跳转系统设置。
- **使用系统原生能力：** 通过 macOS 官方 `SMAppService.mainApp` 登记主应用，不额外安装启动器或后台脚本。
- **真实状态回读：** 每次切换后重新读取登录项状态；若 macOS 正在等待允许或已禁止，会明确显示原因。
- **解释就在旁边：** 开关最右侧保留 info 图标，点击即可查看 Markdown 排版的功能解释、实现逻辑与注意事项。

## 系统要求

- Apple Silicon Mac
- macOS 14 或更高版本

## 重要说明

请将 Lumos 安装到“应用程序”文件夹后再开启登录时启动。关闭该开关只会注销下次登录时的自动启动，不会退出当前 Lumos，也不会中断正在守护的任务。
