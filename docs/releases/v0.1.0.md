# Lumos v0.1.0

发布日期：2026-08-25

Lumos v0.1.0 是首个可下载版本，把长时间任务需要的防休眠能力收敛成清楚、可解释的直接控制。

## 这次带来了什么

- **守护 App：** 选择不能因 Mac 空闲休眠而中断的 App，Lumos 会随目标进程自动启停守护。
- **直接控制：** 分别控制任务运行、屏幕唤醒、低功耗模式与实验性合盖运行。
- **解释就在旁边：** 每项功能最右侧都有 info 图标，点击即可查看 Markdown 排版的功能解释、实现逻辑和注意事项。
- **真实状态回读：** 电源、电池、温度、网络和权限型操作都以系统回读为准，不把请求成功包装成真实生效。
- **安全恢复：** 目标退出、时限到达、电量或温度触发边界，以及 Lumos 退出时，都会撤销属于 Lumos 的高风险控制。

## 系统要求

- Apple Silicon Mac
- macOS 14 或更高版本
