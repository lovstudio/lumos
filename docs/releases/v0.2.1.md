# Lumos v0.2.1

发布日期：2026-08-26

Lumos v0.2.1 修复低功耗模式与合盖控制在系统已经授权后仍可能无法切换的问题，并为升级后尚未完成切换的系统辅助程序提供可操作的修复提示。

## 这次带来了什么

- **系统控制更可靠：** 正式版与开发版使用各自独立的系统辅助程序，避免授权与后台进程相互干扰。
- **升级状态可见：** 如果 macOS 仍在运行旧版辅助程序，主面板与设置页会提示重新启用，而不是让开关无反馈地失败。
- **原地完成修复：** 可直接打开“登录项与扩展”，完成允许后回到 Lumos 重新检测；连接成功时提示自动隐藏。
- **真实状态回读：** 低功耗模式仍只修改当前电源来源，并以 macOS 返回的实际设置作为最终开关状态。

## 系统要求

- Apple Silicon Mac
- macOS 14 或更高版本

## 升级提示

首次打开 v0.2.1 时，macOS 可能要求重新允许 Lumos 的系统辅助程序。若 Lumos 显示“需要重新启用辅助程序”，请在“系统设置 > 通用 > 登录项与扩展”中将 LumosPrivilegedHelper 关闭后重新打开，再回到 Lumos 点击“重新检测”。
